# Исправления замечаний

## Глобальный скролл

Окно редактора ограничено высотой viewport (`100dvh`). Холст, панели параметров, инструменты и содержимое диалогов прокручиваются внутри собственных областей. Панели расположены справа от холста на широком экране и в нижней полосе на узком. Большое изображение и увеличение масштаба не увеличивают страницу. `ResizeObserver` пересчитывает вписывание при изменении размеров области холста.

## Каналы по лабораторной работе 2

Удалён переключатель четырёх режимов преобразования изображения. Числа 1–4 в задании трактуются как количество каналов файла: Gray, Gray + Alpha, RGB, RGB + Alpha. Модель определяется автоматически при загрузке, в панели появляются только её каналы с отдельными монохромными миниатюрами.

Клик по каналу независимо включает или выключает его вклад в главный холст. Только Alpha отображает маску прозрачности; выключенный Alpha показывает непрозрачный цвет. Все выключенные каналы дают чёрный холст. Исходный массив пикселей не изменяется. Сохранение экспортирует документ с применёнными уровнями, фильтрами и изменением размера независимо от временной видимости каналов.

## Цвет текста и публикация

Подписи кнопок инструментов, кнопок масштаба и кнопки «Вписать» получили явный чёрный цвет вместо наследуемого белого. Добавлен `netlify.toml` с командой сборки и папкой публикации `dist`.

Обновлены браузерные тесты `dist/tests/windows.html`: модели файлов, независимое отключение, восстановление исходного изображения, маска Alpha, отсутствие глобального скролла и неизменность экспорта. ## Запуск

Распакуйте архив и откройте `dist/index.html`. Для браузерных тестов и Web Worker запустите сервер командой из README. `dist/js/app.bundle.js` уже обновлён; повторная сборка для обычного запуска не требуется.
